# CroppTech With Commerce

Official corporate website for CroppTech With Commerce.

## Stack
- Next.js
- JavaScript (JSX)
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

The first release is an informational, read-only corporate website. It does not include accounts, checkout, payment processing, or a backend.
